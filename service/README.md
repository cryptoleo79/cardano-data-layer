# cardano-data-layer — service (MVP)

A neutral Cardano data-infrastructure layer, implementing the MVP in
[`../MVP_REPLACEMENT_BLUEPRINT.md`](../MVP_REPLACEMENT_BLUEPRINT.md). It re-floats the
data capabilities orphaned by the TapTools shutdown — **not** as a TapTools clone, but as a
thin proxy over open Cardano sources for commodity market data, plus a curated **project +
category** store (the moat) seeded from the Cardano Memory Layer preservation archive.

## Design

- **Node 22, zero runtime dependencies.** Built only on Node built-ins: `node:http`,
  `node:sqlite`, global `fetch`. No build step, no `node_modules`, nothing to audit.
- **Auto-loading modules.** `src/server.js` discovers every `src/modules/*.js`, runs its
  `init(ctx)`, and registers its routes. Each module is a self-contained vertical slice.
- **Thin proxies, deep moat.** Market data is cached passthrough over open APIs; the project/
  category layer is a local, versioned, provenance-preserving store.

## Run

```sh
cd service
npm start                       # http://127.0.0.1:8787 (creates+seeds the sqlite db on first run)
npm test                        # 36 tests, offline
npm run seed                    # (re)load the project/category seed via versioned upsert
npm run poller                  # price poller daemon that fills the ohlcv table
node src/jobs/ohlcv-poller.js --once   # single tick (cron-friendly; see deploy/poller.crontab)
```

Copy `.env.example` to `.env` to add optional source keys. **History collection:**
install `deploy/poller.crontab` (`( crontab -l 2>/dev/null; grep -v '^#' deploy/poller.crontab ) | crontab -`)
to persist a price tick per tracked token every 5 minutes — the history clock the
OHLCV endpoint aggregates from.

No keys are required to start. Some routes need free credentials to return live data
(set as env vars): `BLOCKFROST_PROJECT_ID` (holders fallback), `OPENCNFT_API_KEY` (NFT,
optional), `DEXHUNTER_PARTNER_ID` (extra price routes). Without them those routes degrade
to a clean `503 source_unavailable` rather than failing.

## Routes

| Route | Source | Status |
|---|---|---|
| `GET /health`, `GET /routes` | — | built-in |
| `GET /token/price?unit=` | DexHunter (+ Minswap cross-check) | live |
| `GET /token/ohlcv?unit=&interval=&limit=` | local `ohlcv` table (filled by poller) | live (raw points) |
| `GET /token/mcap?unit=` | price × Koios supply | live |
| `GET /tokens/top?by=mcap\|volume\|liquidity` | derived (partial coverage, flagged) | live |
| `GET /token/holders?unit=` | Koios → Blockfrost | live w/ Blockfrost key |
| `GET /token/supply?unit=` | Koios / Blockfrost | live |
| `GET /token/metadata?unit=` | CIP-26 (+ on-chain fallback) | live |
| `GET /nft/collection/stats?policy=` | OpenCNFT (swappable) | live w/ network |
| `GET /nft/collection/sales?policy=&page=` | OpenCNFT | live w/ network |
| `GET /categories`, `GET /category/:slug` | local moat store | live |
| `GET /projects?status=&category=&q=&limit=&offset=` | local moat store | live |
| `GET /project/:id` | local moat store (+ history) | live |

`unit` = `policyId + hexAssetName` (e.g. SNEK = `279c909f…534e454b`). `policy` = collection policy id.

Every response carries `source` and `as_of`. Money returns `ada` + `usd` (`usd: null`
when no price route applies). Unknown values are `null` with a `note` — never fabricated.
Derived/illiquid prices are flagged `confidence: 'low'`.

## The moat (project + category)

`src/modules/project.js` is the differentiator. It serves a curated, **versioned** project +
category store. On first start it seeds from `seed/categories.json` (74 cardanocube categories)
and `seed/projects.json` (the 20 "graveyard" / defunct projects), generated by
`seed/generate-seed.mjs` directly from the `cardano-project-memory-archive` custody manifests —
so every seeded project carries its real `archived_wayback_url` + `archived_sha256`. The
`project_history` table is append-only: perishable editorial state is versioned, never silently
overwritten. Category assignments are **not** invented — seeded projects are `unclassified`
until verified assignments exist.

## Status & known limitations

- Market slice finished + live-verified: OHLCV collection (DexHunter), token metadata (CIP-26
  + Koios fallback), and the project + category moat. The four sources are wired; DexHunter,
  Koios, and CIP-26 are confirmed live (keyless). **Blockfrost** needs a free `project_id`
  (returns 403 without one); **OpenCNFT** was DNS-unreachable from the build host — both are
  coded to documented shapes and degrade to a clean `503` until keys/network are provided.
- OHLCV: the poller persists raw price ticks; `/token/ohlcv?interval=1h|1d|…` **aggregates them
  into real o/h/l/c candles on read** (volume null — per-interval on-chain volume not yet
  captured). `interval=raw` returns the ticks verbatim.
- `/tokens/top` ranks only the tracked/seed set (flagged `coverage: 'partial'`) — it does not
  fabricate a full-ecosystem ranking.
- Single-process in-memory cache + one sqlite connection; fine for an MVP, swap for
  Redis/Postgres to scale horizontally.
- Not yet wired: a sustainability/governance model and the editorial curation pipeline that
  makes the moat durable (see `../CARDANO_DATA_LAYER.md` open questions).
